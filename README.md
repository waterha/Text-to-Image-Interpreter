# TIL · Text to Image Interpreter

Windows 后台划词图解工具。选中文字 → 大模型解析概念与关系 → 实时生成 SVG → 在选区上方展示。不是网站，不启动本地 Web 服务，也不捆绑浏览器。

## 使用

1. 双击单文件版 `dist\TIL.exe`；无需安装 Python，也不需要携带依赖文件夹。程序只驻留系统托盘，不显示主窗口，首次运行也不弹出设置。
2. 在任务栏右下角（图标可能在“显示隐藏的图标”中）右键 TIL 图标 →“设置…”，填写供应商名称、上游格式、API 请求地址、API Key 和模型 ID。
3. 点击“测试模型连接”，验证该模型能返回图解；测试会发送内置示例并产生一次 API 调用。
4. 勾选“启用自动划词图解”并保存。WPS PDF 等无法直接读取选区的阅读器，可另外勾选“PDF / 文档兼容划词”。以后拖动鼠标划词，或双击选择文字，图解浮窗会逐步显示。
5. 右键系统托盘图标可暂停、打开设置、查看本地示例或退出。关闭设置窗口不会退出后台程序。

设置仅由托盘右键菜单打开；单击或双击图标不会弹窗。重复启动也不会弹窗或启动第二个实例。配置读取失败、快捷键冲突等后台提示会保留到手动打开设置时显示，不在启动时打断操作。

浮窗优先出现在选区上方；上方空间不足时移到下方，始终限制在当前显示器工作区内。浮窗采用暖纸色的“灵感小笺”样式：轻投影圆角卡片、胶囊关系标签、圆润连线和轻微错位的单列布局；悬停节点时高亮描边。窗口立即显示，不依赖透明度动画；首次图解短暂滑入，生成结束后不持续播放动效，关闭和重绘会取消旧动画。界面回调异常不会停止后续划词/托盘事件；设置中保留不含原文的错误类型提示。内容宽度上限约 380px（长图额外预留滚动条宽度），短图隐藏滚动条并按内容收紧高度；长图可滚动，标题栏可拖动，可导出 SVG。点击 × 会取消当前请求并隐藏浮窗。

### 快捷键与兼容性

- `Alt+Q`：主动读取当前应用选区并图解，不要求开启自动划词；发送的仍是选中的文字。
- 默认通过 Windows UI Automation 只读选区，不限浏览器；支持宿主窗口中的 PDF 子进程，跳过可识别的密码框。实际兼容性取决于应用是否提供选区接口。
- “PDF / 文档兼容划词”默认关闭，需在设置中主动启用。读取失败时，在 WPS、Adobe Reader、Foxit、SumatraPDF、PDF-XChange、Word、OneNote、记事本和主流浏览器等已知文档应用中临时模拟 Ctrl+C。其他应用不模拟 Ctrl+C，以免误伤终端命令；请在支持选区的应用中重新选择后按 Alt+Q。
- 兼容模式先备份可还原的文本/富文本格式，读取选区后还原；不恢复 OLE 内部指针。剪贴板包含无法安全备份的文件、图片或嵌入对象时跳过。若其他程序更新了剪贴板，不用旧内容覆盖它。超时或占用时不能保证还原；后台提示保留在设置中。
- 临时复制可能进入 Windows 剪贴板历史、云同步或被其他剪贴板工具观察到；还原当前剪贴板不能清除这些历史。启用前请确认可接受此行为。
- 图片型、扫描件或禁止复制的 PDF 不等于可选文本；本版本未内置 OCR。请先在阅读器中识别文字，或换用可读取选区的阅读器。兼容模式无法获得准确文字框时，浮窗锚定鼠标划词结束处。
- 高权限程序可能需要相同权限才能读取，受保护窗口或远程桌面不保证兼容；不建议为了划词长期以管理员身份运行。
- 双击、鼠标拖选属于自动触发范围；键盘选择后请按 Alt+Q。

### 首图加速

- 简单的“某层是……，包括 A、B、C”枚举句先本地生成预览，无需等待模型；浮窗明确标注“本地规则预览，尚未经 AI 核对”。不适用的句子不会套用模板编造图解。
- AI 在后台继续分析，DSL 返回第一条完整关系后逐步替换预览。若请求失败，保留标明来源的本地预览，不把它当作 AI 完成结果。
- 模型只输出节点与关系两种逐行指令，不生成 SVG、Mermaid 或布局代码。仅解析完整行；流式更新最多约每 120 毫秒发布一次，最终结果始终提交。
- 本地 Python 生成安全 SVG，直接在 Tkinter Canvas 上绘制矢量图形与文字；不启动浏览器渲染子进程，不依赖 WebView2、pywebview 或 Mermaid.js，不做 SVG → PNG 转换。SVG 导出保留。
- 最多 8 个节点、12 条关系。按依赖分层，每行最多 3 个节点；长标签自动换行，循环、自环、跨层关系使用折线路由。布局针对小图，不提供任意图表类型或复杂图的最优避让；密集交叉关系可能仍需简化原文。
- 最近 5 分钟内相同文本直接复用成功图解，最多保留 16 项内存缓存；更换模型配置时清空，不落盘，不跨启动复用。
- 划词松开后的稳定等待为 80 毫秒。首图/完成用时从应用取得文本后计算，不包含操作系统选区读取时间。DSL 减少格式开销，但实际 Token 和模型等待时间取决于供应商与模型；不承诺固定节省比例。

本地枚举预览和命中缓存以接近即时显示为目标；任意新文本的完整 AI 图解无法承诺 1 秒。若上游首次返回已超过 1 秒，应用不能把等待压到 1 秒以内。请在供应商处确认模型、排队和响应速度；程序不会擅自替换配置的模型。

## 模型设置

支持三种可配置上游格式：

| 格式 | 根地址示例 | 自动补齐的路径 | 认证 |
| --- | --- | --- | --- |
| OpenAI Chat Completions | `https://your-provider.example/v1` | `/chat/completions` | Bearer API Key |
| OpenAI Responses | `https://your-provider.example/v1` | `/responses` | Bearer API Key |
| Anthropic Messages | `https://your-provider.example/v1` | `/messages` | x-api-key |

也可以填完整请求地址。地址中没有路径时自动使用 `/v1`。本机推理服务可用 `http://127.0.0.1:端口/v1`，无需认证时 API Key 可留空。远程请求必须使用 HTTPS，不跟随重定向。

模型须支持文本生成并遵循下述 DSL；不需要图像生成能力。请求优先使用流式响应；上游返回普通 JSON 响应时也支持，但须等待完整响应。不需要用户自行配置提示词，应用会发送协议说明。

```text
+a 存储层 Storage layer
+b 分布式缓存
a>b 包括
+c 关系型数据库
a>c 包括
+d NoSQL 数据库
a>d 包括
```

- `+ID 名称` 定义节点；`来源ID>目标ID 关系` 定义有向连线，关系可省略。
- ID 以英文字母开头，后续为字母、数字或下划线，最长 16 字符；标签允许空格，不需要引号或转义。
- 先定义节点，再引用；必须包含 2–8 个节点和 1–12 条关系。节点标签最多 40 字，关系最多 16 字；不允许控制字符。
- 完全相同的节点/连线会去重，矛盾的重复节点和未定义引用会报错。输出总长度上限为 12000 字符。
- 兼容图前说明、`<think>` / `<analysis>` 思考段、`dsl` / `text` / 无语言标记的 Markdown 围栏；围栏后的说明不进入图。图开始后严格校验指令；不猜测或修补损坏的关系。
- 不再将 Mermaid 或旧版逐行 JSON 作为模型图解协议。未找到 DSL 时明确提示响应格式问题，而不是宣称模型连接不可用。

## 三层结构

1. `til/capture.py` + `clipboard_capture.py`：后台鼠标状态检测、跨进程 UI Automation 选区、密码框过滤，以及可选的文档复制兼容和剪贴板还原。
2. `til/model.py` + `diagram.py`：上游请求、DSL 提示词和流式解析、数量校验、布局、SVG 生成与原生 Canvas 绘制；本地规则预览及示例复用同一绘图实现。
3. `ui.py` + `tray.py` + `app.py`：原生浮窗、SVG 导出、托盘、快捷键、取消与过期结果隔离。`renderer.py` 仅提供原生渲染自检，不启动后台进程。

模型只提供节点和连线文本；XML 由本地代码构造并转义，标签中的 HTML/脚本仅作为文字，不执行、不加载外链。只有实际绘制成功的完整结果才进入内存缓存；关闭浮窗或重新划词后丢弃旧请求结果。

## 隐私

默认关闭自动发送和复制兼容；只有开启自动划词、触发手动快捷键或点击测试后才请求模型。设置窗口打开期间暂停自动捕获。程序不把划词内容和请求日志写入磁盘；成功图解有上述限时内存缓存，兼容复制的系统剪贴板历史风险另见上节。本地预览不联网，但触发图解后仍会请求 AI 更新（命中缓存除外）。API Key 使用 Windows DPAPI 绑定当前账户加密，设置保存在 `%APPDATA%\TIL\settings.json`。供应商地址和模型 ID 是普通配置，不加密。选中内容仍会发送至配置的供应商，请自行确认服务方的数据政策。导出 SVG 是用户主动保存的文件，可能含原文信息。

## 源码运行与打包

需要 Windows 10/11 和 Python 3.11+（建议 64 位，带 Tkinter）。EXE 用户无需 Python；两种方式均不需要 WebView2 Runtime。

```powershell
python -m pip install -r requirements.txt
python main.pyw
python main.pyw --demo
python selfcheck.py
python selfcheck.py --renderer
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

日常启动直接双击 `dist\TIL.exe`，可将此文件复制到桌面或其他目录；启动时不显示控制台，自动解压运行依赖可能需要几秒。配置仍保存在当前 Windows 账户的应用数据目录，不随 EXE 移动。源码运行也可双击 `main.pyw` 或使用 `pythonw main.pyw`。没有内置 API Key，也不自带模型。

`selfcheck.py` 验证 DSL 分片解析、包装内容兼容、安全转义、布局、三种 API 的流式/普通响应、取消和缓存等。`selfcheck.py --renderer` 验证真实 Tk Canvas 绘制、SVG 导出、浮窗隐藏与错误回调，并报告当前进程工作集和绘制时间，不调用模型或读取用户文档。

自检的 `cold_ms` 是 Tk 初始化时间（不含 EXE 解包和 Python 模块导入），`warm_ms` 是三次 Canvas 绘制提交及空闲刷新时间（第一次可能包含字体初始化），不是屏幕扫描显示延迟或模型端到端响应时间。`working_set_mb` 是自检进程的工作集快照，不是应用常驻或峰值内存；不得直接当作完整应用的内存下降比例。

EXE 的独立渲染自检：`dist\TIL.exe --check-renderer build\renderer-check.json`（先确保输出目录存在）。该模式不读取用户设置、不启动划词、不调用模型或显示窗口，仅写入自检状态和时间。

可见浮窗自检：`dist\TIL.exe --check-popup build\popup-check.json`。该模式短暂显示并关闭本地示例，验证加载、实际显示、隐藏和再次显示；不读取设置、不捕获选区、不调用模型。用于排查“Canvas 能画但窗口不显示”的问题。
